# Team Kaushya website

Static site (HTML, CSS, JS). No build step.

## Put it on GitHub Pages
1. Create a new public repository on GitHub, e.g. `team-kaushya`.
2. Upload `index.html`, the `css/` folder and the `js/` folder to the repository root.
3. Go to Settings > Pages. Under Source choose "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/team-kaushya/`.

## Edit
- Email: the `mailto:` link in the `#contact` section of `index.html`.
- Colours: the variables at the top of `css/style.css`.
